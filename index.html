Core capabilities

Four pillars of secure remote work.

Every feature is built around one principle — your intellectual property never leaves your control, even when your team is scattered across time zones.

Exhibit A

Secure proxy layer

Connect your stack — credentials stay on your server, never on an employee's machine.

  • MongoDB database proxy, reachable via localhost
  • GitHub push/pull proxy — tokens never exposed
  • AI CLI / MCP proxy with per-developer audit
  • Custom server proxy (Enterprise)
Exhibit B

Browser sessions (SSO)

One login gives company-controlled access to every tool your team already uses.

  • Notion & Jira under the org account
  • Slack & Discord, isolated from personal accounts
  • Figma & Canva paid seats — no shared passwords
  • Google Drive on org storage, not personal cloud
Exhibit C

Active work telemetry

Proof of work, not surveillance — no screen recording, no keylogging.

  • Idle detection, prompting after 10–15 minutes
  • Workspace file watcher scores code activity
  • GitHub event log — commits, pushes, pulls per dev
  • AI token usage, cost and model per request
Exhibit D

Admin dashboard

Manage your team, infrastructure and billing from a single screen.

  • HRMS and org tree for team hierarchy
  • Proxy session logs with a per-user audit trail
  • SSH keys and server URLs, distributed securely
  • RBAC — Owner → Admin → Manager → Dev → Contractor
How it works

Onboard a contractor in 30 seconds.

Skip the hardware procurement cycle. No VPN setup, no credential emails — just an install and a license key.

01

Admin signs up and gets a license key

The founder or IT admin registers, sets up the organization — DB URIs, GitHub token, AI key — and receives a cryptographic master license key.

02

Invite contractors and employees

Send magic invite links from the dashboard. Each invite consumes one seat and pre-assigns a role — developer, manager, or contractor.

03

Employees install and activate

They download the BroWork app, enter the license key, and are instantly working — with proxied database access, SSO sessions, and telemetry running in the background.
